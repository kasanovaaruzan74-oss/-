# Автоматическая проверка в GitHub Actions

При каждом push и pull request [Python Tests](../../.github/workflows/test.yml) устанавливает зависимости проекта, запускает pytest и прикрепляет файл `pytest.xml` как артефакт `pytest-report`.

Контрольное изменение для проверки результата CI проводится в отдельной ветке. В обработчике `GET /health` временно изменить значение поля `күйі` с `жұмыс істеп тұр` на `контрольная ошибка`. Тест `test_health_response_contract` должен завершиться с `AssertionError`. Следующий коммит восстанавливает исходное значение и повторно запускает проверку. Контрольные коммиты не требуется сливать с основной веткой.
