# GitHub Actions арқылы автоматты тексеру

Әрбір `push` және `pull_request` кезінде жұмыс үдерісі жобаның тәуелділіктерін орнатады, pytest пен Bandit тексерістерін орындайды және `pytest.xml` файлын `pytest-report` артефакті ретінде тіркейді. [Python Tests жұмыс үдерісі](../../.github/workflows/test.yml)

CI қатені анықтайтынын тексеру үшін бақылау өзгерісі жеке `lab08-ci-check` тармағында жасалды. `GET /health` өңдегішінде `күйі` өрісінің `жұмыс істеп тұр` мәні уақытша `контрольная ошибка` мәніне ауыстырылды. `test_health_response_contract` тесті `AssertionError` қатесін тіркеді. Келесі коммит бастапқы мәнді қалпына келтірді, содан кейін барлық тексерістер қайта өтті. [Үш іске қосу нәтижесі](README.md#10-github-actions)
