У документа `DeanDocument` первичный ключ `document_id`. Поле `document_type_id` ссылается на `document_types.document_type_id`, а `document_type` даёт доступ к связанному объекту в Python. Аналогично связаны статус, автор и подразделение документа. Регистрационный номер уникален.

Связь между документами и исполнителями «многие ко многим» задана через `ExecutorAssignment`. У назначения есть ссылки на документ, исполнителя и сотрудника, выдавшего поручение. В нём также можно хранить описание задания и срок. Согласования, история, комментарии и вложения связаны с документом по схеме «один ко многим».

При стандартном значении `DATABASE_URL` скрипт создаёт `deanflow_labs.db` в корне проекта. При повторном запуске скрипт находит существующие демонстрационные записи по их ключам.

Введите пример ниже в интерактивном Python, чтобы проверить структуру готовой базы.

```python
import sqlite3

with sqlite3.connect("file:deanflow_labs.db?mode=ro", uri=True) as db:
    tables = db.execute(
        "SELECT name FROM sqlite_master WHERE type = 'table' ORDER BY name"
    ).fetchall()
    print([name for (name,) in tables])
    print(db.execute("SELECT COUNT(*) FROM documents").fetchone()[0])
    print(db.execute("SELECT COUNT(*) FROM document_approvals").fetchone()[0])
    print(db.execute("PRAGMA foreign_key_list(documents)").fetchall())
    print(db.execute("PRAGMA foreign_key_check").fetchall())
```

В учебной схеме документооборота 11 таблиц. В новой базе посев добавляет в каждую из них от трёх до четырёх записей, включая четыре карточки документов и три согласования. В итоговой версии есть две дополнительные таблицы для учётных данных и сессий пользователей. Последняя строка должна вывести `[]`, если все ссылки между таблицами корректны.

## Контрольные вопросы

1. **Что такое ORM?** Object-Relational Mapping сопоставляет Python-классы и реляционные таблицы. SQLModel и SQLAlchemy формируют SQL для чтения и сохранения объектов и управляют изменениями в рамках сессии.
2. **Чем внешний ключ отличается от `Relationship`?** `document_type_id` — колонка с идентификатором строки справочника. `document_type` — ORM-атрибут для доступа к объекту типа документа. Отдельной колонки для этого атрибута в таблице нет.
3. **Зачем нужен посев данных?** Одинаковые учебные документы и справочники позволяют сразу проверить список, фильтры и формы. С пустой базой сложно показать поиск и выбрать связанные записи для новой карточки.
4. **Что даёт `echo=True`?** Движок SQLAlchemy выводит выполняемые SQL-операторы и параметры. При отладке можно увидеть создание таблиц, порядок запросов и фиксацию транзакций. Логирование разумно включать для учебных данных.
5. **Почему в Git хранится модель, а база исключена?** Модель описывает воспроизводимую схему и удобно проверяется в diff. SQLite-файл содержит текущее локальное состояние и может включать изменённые данные.
