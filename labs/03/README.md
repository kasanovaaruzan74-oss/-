## Цель

Открыть доступ к реестру документов по HTTP. Запуск сервера, чтение, создание записей, валидация входа и управление сессией БД демонстрируются в Swagger UI.

## Как устроен сервер

[`app/main.py`](../../app/main.py) создаёт приложение FastAPI, инициализирует таблицы при запуске и подключает роутер. Маршруты находятся в [`app/routers/documents.py`](../../app/routers/documents.py). Зависимость `Depends(get_session)` открывает сессию SQLModel на время запроса и закрывает её при выходе из контекстного менеджера. [`DocumentCreate` и `DocumentRead`](../../app/database/models.py) задают контракт входных и возвращаемых полей. Идентификатор, регистрационный номер и дата регистрации задаются на стороне сервера.

| Метод и путь | Результат |
| --- | --- |
| `GET /` | `200`. Краткая информация об API и ссылка на документацию. |
| `GET /health` | `200`. Сервер отвечает. |
| `GET /documents` | `200`. JSON-массив карточек. |
| `GET /documents/{document_id}` | `200` и одна карточка, либо `404` для отсутствующего идентификатора. |
| `GET /documents/lookups` | `200`. Типы, статусы и подразделения для форм. |
| `POST /documents` | `201` и созданная карточка, либо `422` для недопустимых данных. |

## Демонстрация

В активированном окружении запустите посев данных, затем Uvicorn. Команды выполняются из корня проекта.

```bash
python -m app.database.seed
python -m uvicorn app.main:app --reload
```

Откройте [Swagger UI](http://127.0.0.1:8000/docs). Для каждого примера выберите операцию и нажмите **Try it out** → **Execute**.

1. Выполните `GET /documents` и возьмите `document_id` из ответа. Затем выполните `GET /documents/{document_id}` для этого номера.
2. Через `GET /documents/lookups` проверьте доступные типы и статусы. Для свежей базы подходит пример ниже. Если база уже заполнена вручную, подставьте идентификаторы из справочника. Выполните `POST /documents` и сохраните `document_id` из ответа `201`.
3. Повторите `POST` с `"title": "А"`. Ожидается `422`, так как заголовок должен содержать минимум три символа.
4. Выполните `GET /documents/{document_id}` с отсутствующим ID. Ожидается `404`.

### Пример тела POST

```json
{
  "title": "Заявление на выдачу справки",
  "description": "Учебная карточка для защиты",
```

## Контрольные вопросы

1. **Что такое REST API и в чём разница между GET и POST?** REST API представляет ресурсы по адресам. `GET /documents` читает реестр, а `POST /documents` отправляет данные для создания новой карточки и меняет состояние системы.
2. **Для чего Pydantic?** Он разбирает JSON, проверяет типы, обязательность, длины и разрешённые значения. Например, короткий заголовок отклоняется до сохранения записи.
3. **Что даёт `Depends(get_session)`?** FastAPI управляет временем жизни зависимости и может подменить её в тесте. Общая сессия на все запросы смешивала бы состояние транзакций и создавала бы проблемы при параллельной обработке.
4. **Откуда берётся Swagger UI?** FastAPI строит OpenAPI-спецификацию из объявлений маршрутов, типов параметров и моделей. Swagger UI использует эту спецификацию и доступен по `/docs`.
5. **Что означает `422`?** Сервер получил запрос, но данные нарушают контракт. Например, заголовок короче трёх символов, дата имеет неверный формат или выбранного типа документа нет в справочнике.
