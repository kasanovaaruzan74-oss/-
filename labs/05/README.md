# Лабораторная работа № 5. Веб-интерфейс Streamlit

**Цель** — связать интерфейс деканата с FastAPI по HTTP и дать сотруднику деканата возможность просматривать, искать, регистрировать и удалять учебные документы.

## Реализация

Интерфейс загружает справочники типов, статусов и подразделений из `GET /documents/lookups`. Список документов запрашивается через `GET /documents` и отображается в таблице. Боковая панель передаёт на сервер параметры `search`, `status_code` и `direction`. Формы отправляют `POST /documents` для регистрации и `DELETE /documents/{document_id}` для удаления выбранного документа. Клиент задаёт тайм-аут запросов и показывает сообщение при сбое связи с сервером. [Код интерфейса](../../app/frontend/ui.py) · [Маршруты API](../../app/routers/documents.py)

## Запуск и показ преподавателю

Из корня репозитория установите зависимости в активном виртуальном окружении, заполните SQLite учебными данными и запустите API.

```bash
python -m pip install -r requirements.txt
python -m app.database.seed
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Во втором терминале с этим же виртуальным окружением запустите интерфейс.

```bash
python -m streamlit run app/frontend/ui.py
```

1. Откройте интерфейс и найдите документ по части регистрационного номера `DF-DEMO-0001`. Сбросьте строку поиска и в поле `Мәртебесі` выберите статус `Тіркелді`, чтобы показать серверную фильтрацию по статусу. [Интерфейс](http://localhost:8501)
2. Сбросьте фильтры, задайте тему `Проверка ЛР 05`, выберите тип документа и нажмите `Құжатты тіркеу`. Покажите строку в таблице и присвоенный регистрационный номер.
3. В разделе `Құжатты жою` выберите созданный для проверки документ, поставьте отметку `Құжатты жоюды растаймын` и нажмите `Жою`. Проверьте, что документ исчез из таблицы.
4. Откройте Swagger UI и покажите, какие поля и query-параметры поддерживают используемые маршруты. [Swagger UI](http://localhost:8000/docs)

## Контрольные вопросы

- **Как Streamlit и FastAPI обмениваются данными?** Браузер отображает интерфейс Streamlit. Python-код Streamlit вызывает API через HTTP с помощью `requests`. FastAPI валидирует данные, обращается к SQLite через SQLModel и возвращает HTTP-статус и, если у операции есть тело ответа, JSON.
- **Чем различаются `params` и `json` в `requests`?** `params` кодирует значения в строке запроса URL, например `?status_code=REGISTERED`. `json` сериализует объект в тело запроса с типом содержимого `application/json`.
- **Что увидит пользователь при остановке API?** Запрос завершится ошибкой соединения или тайм-аутом. Streamlit сообщит, что не удалось подключиться к серверу, и предложит проверить запуск FastAPI.
- **Почему Streamlit выполняет сценарий повторно?** Изменение значения виджета запускает новый проход скрипта, который строит интерфейс с текущим состоянием. Виджеты внутри формы передают значения при её отправке.
- **Когда Streamlit подходит для проекта?** Он позволяет быстро собрать таблицы, фильтры и формы на Python. Для сложного роутинга, произвольной вёрстки и низкоуровневого управления браузером обычно требуются дополнительные компоненты или классический веб-фронтенд.
