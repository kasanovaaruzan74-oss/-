# № 5 зертханалық жұмыс. Streamlit веб-интерфейсі

**Мақсаты** — деканат интерфейсін FastAPI серверімен HTTP арқылы байланыстырып, қызметкерге оқу құжаттарын қарау, іздеу, тіркеу және жою мүмкіндігін беру.

## Іске асыру

Интерфейс құжат түрлері, мәртебелері және бөлімдер туралы анықтамалықтарды `GET /documents/lookups` арқылы жүктейді. Құжаттар тізімін `GET /documents` арқылы алып, кестеде көрсетеді. Бүйірлік панель серверге `search`, `status_code` және `direction` сұрау параметрлерін жібереді. Тіркеу нысаны `POST /documents` сұрауын, жою нысаны таңдалған құжат үшін `DELETE /documents/{document_id}` сұрауын жібереді. Клиент әр сұрауға күту уақытын белгілейді. Сервермен байланыс үзілсе, интерфейс қате туралы хабарлама көрсетеді. [Интерфейс коды](../../app/frontend/ui.py) · [API маршруттары](../../app/routers/documents.py)

## Іске қосу және қорғау

Репозиторийдің түбірлік бумасында виртуалды ортаны белсендіріңіз. Тәуелділіктерді орнатыңыз, SQLite дерекқорын оқу деректерімен толтырыңыз және API серверін іске қосыңыз.

```bash
python -m pip install -r requirements.txt
python -m app.database.seed
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Екінші терминалда сол виртуалды ортаны белсендіріп, интерфейсті іске қосыңыз.

```bash
python -m streamlit run app/frontend/ui.py
```

1. Интерфейсті ашып, іздеу жолағына `DF-DEMO-0001` тіркеу нөмірін немесе оның бір бөлігін енгізіңіз. Іздеу жолағын тазалап, `Мәртебесі` өрісінен `Тіркелді` мәнін таңдаңыз. Кестеге серверден осы мәртебедегі құжаттар ғана келгенін көрсетіңіз. [Интерфейс](http://localhost:8501)
2. Сүзгілерді бастапқы күйіне қайтарыңыз. Құжат тақырыбына `№ 05 зертханалық жұмысты тексеру` деп жазыңыз, құжат түрін таңдап, `Құжатты тіркеу` батырмасын басыңыз. Кестедегі жаңа жолды және құжатқа берілген тіркеу нөмірін көрсетіңіз.
3. `Құжатты жою` бөлімінен жаңа ғана жасаған құжатты таңдаңыз. `Құжатты жоюды растаймын` құсбелгісін қойып, `Жою` батырмасын басыңыз. Құжаттың кестеден өшкенін тексеріңіз.
4. Swagger UI бетін ашып, қолданылған маршруттардың кіріс өрістері мен сұрау параметрлерін көрсетіңіз. [Swagger UI](http://localhost:8000/docs)

## Бақылау сұрақтары

- **Streamlit пен FastAPI деректермен қалай алмасады?** Браузер Streamlit интерфейсін көрсетеді. Streamlit қолданбасының Python коды `requests` арқылы API серверіне HTTP сұрауын жібереді. FastAPI кіріс деректерін тексереді, SQLModel арқылы SQLite дерекқорына жүгінеді және HTTP күй кодын қайтарады. Жауапта деректер болса, олар JSON пішімінде беріледі.
- **`requests` кітапханасындағы `params` пен `json` аргументтерінің айырмашылығы қандай?** `params` мәндерді URL мекенжайының сұрау бөлігіне қосады, мысалы `?status_code=REGISTERED`. `json` Python нысанын JSON пішіміне түрлендіріп, сұрау денесіне жазады және мазмұн түрін `application/json` деп белгілейді.
- **API тоқтаса, пайдаланушы не көреді?** Сұрау байланыс қатесімен аяқталады немесе күту уақыты бітеді. Streamlit серверге қосыла алмағанын хабарлап, FastAPI іске қосылғанын тексеруді ұсынады.
- **Streamlit сценарийді не үшін қайта орындайды?** Виджет мәні өзгерген кезде бағдарлама сценарийді қайта іске қосып, интерфейсті ағымдағы мәндермен құрады. Нысан ішіндегі виджет мәндері нысанды жіберген кезде бірге беріледі.
- **Streamlit қандай жобаларға ыңғайлы?** Python тілінде кестелерді, сүзгілерді және нысандарды жылдам құруға ыңғайлы. Күрделі маршруттар, еркін бет құрылымы және браузерді тікелей басқару қажет болғанда, әдетте қосымша компоненттер немесе дәстүрлі веб-интерфейс қолданылады.
