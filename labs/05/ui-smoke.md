# Проверка веб-интерфейса DeanFlow

Streamlit AppTest выполнял сценарии из `app/frontend/ui.py` с настоящими HTTP-запросами к FastAPI. Для каждого сценария использовалась временная SQLite, заполненная командой `python -m app.database.seed`. Бэкенд запускался через `python -m uvicorn app.main:app --host 127.0.0.1 --port <свободный порт>`. Тестовые базы удалялись после завершения.

## Обычный учебный запуск

| Действие | Наблюдение |
| --- | --- |
| Открытие страницы | В списке 4 исходные записи, API вернул HTTP 200. |
| Поиск `UI live check` | API получил параметр `search`. Совпадений пока нет. |
| Форма регистрации | `POST /documents` вернул HTTP 201. Строка и уведомление появились сразу. |
| Подтверждение удаления | `DELETE /documents/5` вернул HTTP 204. Строка исчезла, появилось уведомление об удалении. |
| Проверка удалённой записи | `GET /documents/5` вернул HTTP 404. |

## Запуск с `AUTH_REQUIRED=true`

| Действие | Наблюдение |
| --- | --- |
| Открытие в новом сеансе | UI показал форму входа. Прямой `GET /documents` без токена вернул HTTP 401. |
| Вход администратора | `POST /auth/login` вернул HTTP 200, таблица показала 4 строки и форму удаления. |
| Выход администратора | `POST /auth/logout` вернул HTTP 204. Следующий запрос с предыдущим токеном получил HTTP 401. |
| Вход исполнителя | После `POST /auth/register` с HTTP 201 исполнитель вошёл через UI, получил 4 строки и увидел только доступные действия. |

Оба живых прогона завершились успешно. AppTest с моделированием HTTP дополнительно подтвердил предупреждение при попытке удаления без отметки подтверждения, очистку локальной сессии при недоступном API выхода и переход к форме входа после истечения срока токена.
