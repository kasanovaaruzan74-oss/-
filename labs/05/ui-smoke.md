# DeanFlow веб-интерфейсін тексеру

Streamlit AppTest құралы `app/frontend/ui.py` сценарийлерін FastAPI серверіне нақты HTTP сұрауларын жіберіп тексерді. Әр сценарий үшін бөлек уақытша SQLite дерекқоры жасалып, `python -m app.database.seed` командасымен толтырылды. Сервер `python -m uvicorn app.main:app --host 127.0.0.1 --port <бос порт>` командасымен іске қосылды. Тексеру аяқталған соң уақытша дерекқорлар жойылды.

## Оқу режимінде іске қосу

| Әрекет | Байқалған нәтиже |
| --- | --- |
| Бетті ашу | Тізімде төрт бастапқы жазба көрсетілді. API HTTP `200` қайтарды. |
| `UI live check` мәні бойынша іздеу | API `search` параметрін алды. Бұл мәнге сәйкес құжат әлі болған жоқ. |
| Тіркеу нысанын жіберу | `POST /documents` HTTP `201` қайтарды. Жаңа жол мен хабарлама бірден көрсетілді. |
| Құжатты жоюды растау | `DELETE /documents/5` HTTP `204` қайтарды. Жол кестеден өшіп, жойылғаны туралы хабарлама көрсетілді. |
| Жойылған жазбаны тексеру | `GET /documents/5` HTTP `404` қайтарды. |

## `AUTH_REQUIRED=true` параметрімен іске қосу

| Әрекет | Байқалған нәтиже |
| --- | --- |
| Бетті жаңа сеанста ашу | Интерфейс кіру нысанын көрсетті. Токенсіз тікелей жіберілген `GET /documents` сұрауы HTTP `401` алды. |
| Әкімшінің кіруі | `POST /auth/login` HTTP `200` қайтарды. Интерфейс төрт жолдан тұратын кесте мен жою нысанын көрсетті. |
| Әкімшінің шығуы | `POST /auth/logout` HTTP `204` қайтарды. Алдыңғы токенмен жіберілген келесі сұрау HTTP `401` алды. |
| Орындаушының кіруі | `POST /auth/register` HTTP `201` қайтарғаннан кейін орындаушы интерфейс арқылы кірді. Ол төрт жазбаны және өз рөліне рұқсат етілген әрекеттерді көрді. |

Нақты API қолданылған екі тексеру де сәтті аяқталды. HTTP жауаптарын модельдеген қосымша AppTest сценарийлері мына әрекеттерді растады. Құсбелгі қойылмай құжатты жою әрекеті жасалса, ескерту көрсетіледі. Шығу маршруты қолжетімсіз болса, жергілікті сеанс тазаланады. Токеннің мерзімі аяқталса, кіру нысаны қайта ашылады.
