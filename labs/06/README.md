# № 6 зертханалық жұмыс. Docker Compose арқылы контейнерлеу

**Мақсаты** — FastAPI мен Streamlit қолданбаларын бөлек контейнерлерде іске қосу, оларды Compose желісі арқылы байланыстыру және қайта іске қосылғанда SQLite дерекқорын сақтау.

## Іске асыру

| Компонент | Баптауы |
| --- | --- |
| `backend` | `python:3.11-slim` бейнесі, іске қосылғанда SQLite дерекқорын үлгі деректермен толтыру, `8000` портындағы Uvicorn сервері және `GET /health` арқылы дайындықты тексеру. |
| `frontend` | `python:3.11-slim` бейнесі, `8501` портындағы Streamlit, API дайын болғанша күту, `BACKEND_URL=http://backend:8000` мекенжайы және `/_stcore/health` арқылы дайындықты тексеру. |
| Деректерді сақтау | `deanflow-demo-data` атаулы томы контейнердің `/data` бумасына жалғанады. API `/data/deanflow-labs.db` файлын пайдаланады. |
| Құрастыру контексі | `.dockerignore` виртуалды орталарды, кэшті, жергілікті дерекқорларды және әзірлеу ортасының басқа файлдарын құрастыру контексінен шығарады. |

## Іске қосу және қорғау

Docker іске қосылғанын және `8000`, `8501` порттары бос екенін тексеріңіз. Репозиторийдің түбірлік бумасында мына командаларды орындаңыз.

```bash
docker compose config --quiet
docker compose up --build -d
docker compose ps
docker compose logs --tail 40 backend frontend
```

Compose екі сервистің портын да `127.0.0.1` мекенжайына байланыстырады. Порттар бос болмаса, іске қоспас бұрын `DEANFLOW_API_PORT` және `DEANFLOW_UI_PORT` айнымалыларына бос порттарды беріп, браузерде сол порттарды пайдаланыңыз.

1. `docker compose ps` нәтижесінен екі сервистің де дайындық күйін көрсетіңіз. `/health` және Swagger UI беттерін ашыңыз. [API жұмысын тексеру](http://localhost:8000/health) · [Swagger UI](http://localhost:8000/docs)
2. Streamlit интерфейсінен үлгі құжатты табыңыз. `№ 06 зертханалық жұмыс. Томды тексеру` атты бөлек құжат жасап, тіркеу нөмірін жазып алыңыз. [Интерфейс](http://localhost:8501)
3. `docker compose down` командасын, содан кейін `docker compose up -d` командасын орындаңыз. Сервистер іске қосылған соң құжатты сол тіркеу нөмірі бойынша тауып, оқу жазбасын интерфейс арқылы жойыңыз.

## Тексеру нәтижесі

Docker Compose v2.40.3 нұсқасында екі сервис те `healthy` күйіне өтті. Дайындық маршруттары мен Swagger UI HTTP `200` қайтарды. Streamlit контейнерінен `http://backend:8000/documents` мекенжайына жіберілген сұрау төрт үлгі құжаттың бәрін қайтарды. `down` және `up` командаларынан кейін тексеру кезінде жасалған құжат HTTP `200` кодымен қайта оқылып, HTTP `204` кодымен жойылды.

`AUTH_REQUIRED=true` режимінде `/documents` маршрутына токенсіз жіберілген сұрау HTTP `401` алды. Уақытша әкімшінің кіру сұрауы HTTP `200` алды. Әкімші токенмен жіберген сұрау HTTP `200` кодымен төрт үлгі құжатты да қайтарды. Streamlit-тің басты беті мен дайындық маршруты HTTP `200` қайтарды. [Авторизация режимін баптау](../08/README.md)

Тексеру ортасында бейнелерді құрастыру үшін желілік проксидің сенімді сертификаты BuildKit арқылы уақытша құпия дерек ретінде берілді.

## Бақылау сұрақтары

- **Контейнердің виртуалды машинадан айырмашылығы қандай?** Контейнер процесті, файлдық жүйені және желіні оқшаулайды әрі хост жүйенің ядросын пайдаланады. Виртуалды машина өз қонақ операциялық жүйесі мен ядросын іске қосады.
- **Dockerfile нұсқаулары не үшін қолданылады?** `WORKDIR` жұмыс бумасын белгілейді. `COPY` файлдарды бейнеге көшіреді. `EXPOSE` қолданба пайдаланатын портты сипаттайды. `RUN` құрастыру кезінде команданы орындайды. `CMD` контейнер іске қосылғанда әдепкі орындалатын команданы белгілейді. Портты хостқа ашу Compose файлындағы `ports` арқылы бапталады.
- **`.dockerignore` файлы не үшін қажет?** Ол құрастыру контексін кішірейтіп, әзірлеу ортасының жергілікті файлдарын алып тастайды. `venv` бумасы көшірілсе, бейнеге артық тәуелділіктер, әзірлеушінің жүйесіне байланған жолдар немесе екілік файлдар түсуі мүмкін.
- **`http://backend:8000` мекенжайы қалай жұмыс істейді?** Compose желісіндегі Docker DNS қызметі `backend` атауына тиісті контейнердің IP мекенжайын қайтарады. Хосттан контейнерге жарияланған порт арқылы қосыламыз, сондықтан Swagger UI `localhost:8000` мекенжайында ашылады.
- **`docker compose down` командасынан кейін SQLite дерекқоры не болады?** Дерекқор файлы атаулы томда сақталады. `down -v` командасы томды да жояды.
