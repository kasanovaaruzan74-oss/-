# Проверка исходного DeanFlow на ASP.NET Core

25 ноября 2026 года проект собран с .NET SDK `10.0.404`.

```text
dotnet build --nologo Деканат.csproj
Build succeeded.
    0 Warning(s)
    0 Error(s)
```

При запуске через профиль `http` маршрут `/Account/Login` ответил `HTTP 200`. Заголовок открытой формы входа был `Жүйеге кіру · UniDoc Space`.

Для проверки авторизации и работы с документами нужна подготовленная база `DeanFlowDB`. Настройки SQL Server описаны в [инструкции по запуску](../README.md#негізгі-веб-қосымшаны-іске-қосу).
